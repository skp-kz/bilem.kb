**Статус:** принято, 23.10.2026 (Слава). Отменяет двустороннюю схему «код заявки → код из кабинета» (#56, #75, #76).

## Решение

Кода заявки больше нет. Есть один **код подключения** `XXXX-XXXX`: рождается в кабинете, вводится в агенте.

**Почему.** Владелец уже дважды доказал, что база его: вошёл в кабинет через identity provider (Google/Microsoft/…) и вошёл на сервер администратором с паролем 1С. Третья проверка (заявка с сервера, подтверждаемая в кабинете) ничего не добавляет и только удлиняет путь. В оферте: Bilem — шлюз, за то, чью базу подключили, отвечает тот, кто подключал.

## Как работает

### Владелец сам
1. Кабинет → 1С-Базы → **«Подключить базу»** → кабинет проверяет лимит тарифа и показывает код `XXXX-XXXX` (10 минут, один раз) + «Скопировать».
2. На сервере в Bilem Agent: вкладка MCP → у базы **«Подключить…»** → окно с одним полем «Код из кабинета» → «Подключить».
3. Агент отдаёт облаку код + сведения о базе (имя, конфигурация, организации с БИН, компьютер) → облако по коду находит кабинет, привязывает базу, выдаёт агенту ключ. В кабинете база появляется через пару секунд.

### Поддержка СКП (тумблер у клиента включён)
1. В кабинете клиента (роль support) → **«Подключить базу»** → владельцу в WhatsApp: «Сотрудник СКП (имя) хочет подключить базу к вашему кабинету (адрес). Разрешить?» [Разрешить / Отклонить], 10 минут.
2. «Разрешить» → в кабинете появляется код `XXXX-XXXX`.
3. Дальше как у владельца: код в агент на сервере клиента (по RDP/TeamViewer). На сервере — никаких браузеров и аккаунтов. Владельцу после подключения — «База «…» подключена», всё в журнале.

Код не привязан к конкретной базе — какую базу подключить, выбирают в агенте. В WhatsApp-запросе поэтому нет имени базы: владелец разрешает одно подключение (один код = одна база), а что именно подключили — видит в сообщении «База «…» подключена» и в кабинете.

## Протокол (согласовать Земле и Воздуху в карточках)

- Кабинет: `POST /api/cloud/codes` → `{ code, expires_at }` (владелец/админ — сразу; support — после «Разрешить» в WhatsApp). В D1 — только хеш, как сейчас.
- Агент: `POST /agent/v1/connect` с `code`, сведениями о базе, `machine`, `agent_version` → `{ base_id, org: { slug, name, mcp_url }, key }`. Ошибки: `code_invalid`, `code_expired`, `code_used`, `limit`, `too_many_attempts` (5 попыток).
- `POST /agent/v1/connect-requests` и страница `/connect?r=` — убрать (один релиз подержать для агентов 0.3.0, потом снести).
- В агенте окно «Подключить…» = база, поле «Код из кабинета», подпись «Код — в кабинете app.bilem.ai → 1С-Базы → Подключить базу», кнопка «Подключить». Без кода заявки, без «Открыть в браузере».

## Что меняется в кабинете

«Подключить базу по коду» (#76) → просто «Подключить базу»: кнопка → код (или ожидание WhatsApp для support) → шаги «поставьте агент → введите код». Поля для ввода кода заявки нет.
