**Дата:** 21.10.2026 · **Кто ставит:** Слава · **Участники:** Воздух, Земля · **Статус:** ✅ пройден 21.10, карточка #54

Первый живой тест оркестратора из [решения 0016](/decisions/0016-orkestrator-mcp): агенты общаются через карточку на доске **Стенд** (bilem.dev/?board=stand), каждый под своим именем. Будильника пока нет — каждого агента в нужный момент пингует Слава.

## Как устроен доступ

- Доска: MCP-сервер `https://bilem.dev/api/mcp` (инструменты `whoami`, `list_cards`, `get_card`, `create_card`, `comment_card`, `move_card`, `update_card`, `list_users`). Кто владелец ключа `bd_` — тот и автор.
- Ключи `bd_` лежат **в шлюзе mcp.skp.kz** (MCPHub), у агента — только его вход в шлюз. Записи серверов в шлюзе: `bilem-dev-zemlya`, `bilem-dev-vozduh` (заведены 21.10, выключены до того, как Слава впишет ключи).
- Адреса для агентов:
  - **Земля** (Claude Code): `https://mcp.skp.kz/mcp/bilem-dev-zemlya` + заголовок `Authorization: Bearer <ключ MCPHub Земли>`.
  - **Воздух**: `https://mcp.skp.kz/mcp/bilem-dev-vozduh` + заголовок `Authorization: Bearer <ключ MCPHub Воздуха>`.
  - **Buddy (ChatGPT)** — позже, напрямую через OAuth, без ключа в заголовке (отдельная задача).
- Ключи в чат, карточки, коммиты и эту базу знаний не пишем.

## Подключение

- **Земля:** `claude mcp add --scope user --transport http bilem-dev https://mcp.skp.kz/mcp/bilem-dev-zemlya --header "Authorization: Bearer <ключ MCPHub Земли>"` → перезапустить Claude Code → вызвать `whoami`, должно быть `zemlya`.
- **Воздух:** так же, своим адресом и ключом; `whoami` → `vozduh`.

## Сценарий теста

1. **Воздух** создаёт карточку: `create_card` → `board: stand`, `column: next`, `title: "Проверка связи: Земля, ответь #земля"`, `description: "Ответь комментарием: версия агента на стенде и что сейчас в работе."`. Тег `#земля` сам назначит исполнителем Землю. Воздух сообщает Славе номер карточки.
2. Слава пишет Земле: «проверь доску Стенд».
3. **Земля**: `list_cards` (`board: stand`, `assignee: me`) → `get_card` → `comment_card` с ответом. Карточку **не закрывает** — она чужая (автор — Воздух).
4. Слава пишет Воздуху: «Земля ответил».
5. **Воздух**: `get_card` → читает ответ → `move_card` в `done` и короткий комментарий «принято».

**Успех:** в истории карточки на bilem.dev видно: создал — Воздух, исполнитель — Земля, комментарий — Земля, перенёс в «Готово» — Воздух.

## Результат (21.10)

Карточка **#54** на доске Стенд: 22:42 создал Воздух (исполнитель Земля по тегу) → 22:50 ответила Земля (Claude Code 2.1.299, opus-5-5, стенд BAKANOF; в работе пусто) → 23:10 Воздух перенёс в «Готово», комментарий «принято». Оба агента — под своими логинами через mcp.skp.kz.

Что выяснили по дороге:

- MCP-сервер добавлять с `--scope user`, иначе он виден только из папки, где выполнялась команда.
- Служба Remote Control на homeos (`claude-rc`, окружение `work`) берёт список серверов при старте — после `claude mcp add` её надо перезапустить: `sudo systemctl restart claude-rc`. Окружение `bilem.cfe-dev` — другой процесс, без доски.
- Окружение в приложении называется по папке запуска (Земля сейчас — `system32`); имя пробуем задать через `claude remote-control --name …`.
- Чтобы агент не спрашивал разрешения на каждый вызов: `"mcp__bilem-dev"` в `permissions.allow` его `~/.claude/settings.json`.
- Remote Control на стенде умирает вместе с окном PowerShell — нужен автозапуск (вместе с мостом earth-gh).

## Чего не делать

- Не закрывать и не двигать чужие карточки — только комментировать.
- Не писать в карточки ключи, пароли, данные клиентов.
