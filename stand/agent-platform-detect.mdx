Соседняя страница — [агент v0.3](/stand/agent-app-v03) (части A–J).

## Откуда задача

QA-тестер Александр Шевченко, v0.3.0-beta.12, Windows, файловая база. 1С на компьютере стоит, а онбординг на шаге 3 пишет:

```
[FAIL] Платформа 1С:Предприятие 8.3 не найдена.
[FAIL] Что делать: Установите платформу 1С:Предприятие 8.3 с компонентой «Модули расширения веб-сервера».
```

Сообщение вводит в заблуждение: человек видит, что 1С установлена, и не понимает, что не так. sysinfo в этом случае тоже пишет только «платформа не найдена» — разобрать по файлу нельзя.

Сейчас `Platform.Find()` смотрит только `%ProgramW6432%\1cv8\8.3.x.x\bin\comcntr.dll` и `Program Files (x86)\1cv8\…`. Всё остальное молча отбрасывается.

## Политика (решение Славы 20.10)

**Bilem работает только с полной платформой 8.3** — это основная масса бухгалтерий. Всё остальное — не ошибка «не найдено», а понятный отказ с объяснением. Учебная версия, 8.4/8.5 и прочее — ждут своей очереди.

## Что сделать

### 1. Искать шире и запоминать, что нашли и почему отбросили

Новый метод (условно `Platform.Survey()`), возвращает **все** найденные установки с причиной, а не только годные:

| Где искать | Что это |
| --- | --- |
| `Program Files\1cv8\*`, `Program Files (x86)\1cv8\*` | обычная установка (как сейчас) |
| `%LOCALAPPDATA%\Programs\1cv8\*` каждого профиля (минимум — текущего пользователя и того, под кем запущен онбординг) | установка «для текущего пользователя» |
| `Program Files\1cv8t\*`, `Program Files (x86)\1cv8t\*`, `%LOCALAPPDATA%\Programs\1cv8t\*` | **учебная версия** |
| реестр Uninstall (64 и 32): `DisplayName` содержит «1С:Предприятие» / «1C:Enterprise» + `InstallLocation` | страховка: нестандартная папка |

Для каждой установки определить:

- **версия** — из имени папки (`8.3.25.1374`); принимать любые `8.\d+.\d+.\d+`, а не только `8.3`, чтобы распознать 8.4/8.5;
- **разрядность** — по корню (как сейчас) или по PE-заголовку `1cv8.exe`;
- **учебная** — любой из признаков: папка `1cv8t`, в `bin` есть `1cv8t.exe` и нет `1cv8.exe`, `DisplayName` в Uninstall содержит «учебная» / «Training»;
- **COM-коннектор** — есть ли `bin\comcntr.dll`;
- **модули веб-сервера** — есть ли `bin\wsisapi.dll` (для IIS) / `wsap24.dll` (для Apache).

### 2. Выбор и сообщения

Годная = полная (не учебная) + 8.3 + есть `comcntr.dll`. Выбор среди годных — как сейчас (самая новая, при равенстве 64-бит). Установка «для пользователя» — **годная**, если проходит те же условия (проверить, что регистрация COM и webinst работают из этой папки; если нет — отдельное сообщение).

Если годной нет — показать **самую близкую** найденную и одно из сообщений (тексты — в `Strings.resx`, RU/KZ):

| Ситуация | Сообщение |
| --- | --- |
| Только учебная | «Найдена учебная версия 1С:Предприятие {версия} ({путь}). Bilem с ней не работает: в учебной версии нет COM-соединения. Нужна полная платформа 1С:Предприятие 8.3.» |
| Полная 8.3 без `comcntr.dll` | «Найдена 1С:Предприятие {версия} ({путь}), но без COM-коннектора. Запустите установку этой платформы → «Изменить» → отметьте компонент «1С:Предприятие» и «Модули расширения веб-сервера».» |
| Не 8.3 (8.4, 8.5…) | «Найдена 1С:Предприятие {версия}. Bilem пока работает только с платформой 8.3.» |
| Ничего | как сейчас + строка «Искали в: …» (список папок) |

Несколько установок — в журнал все, по строке: версия, разрядность, полная/учебная, COM да/нет, веб-модули да/нет, путь (путь к профилю — без имени пользователя, `%LOCALAPPDATA%\…`).

### 3. sysinfo

В «Собрать системную информацию» — тот же список из `Survey()` вместо «платформа не найдена». Пути профилей маскировать, как сейчас принято.

### 4. Известные ошибки

`docs/known-issues.md` — новый пункт «1С установлена, а агент её не видит»: учебная версия, установка без COM, установка для пользователя, не 8.3.

## Что сдать

- Релиз с `Survey()`, сообщениями и sysinfo.
- Тесты на разбор папок: `1cv8\8.3.25.1374` (годная), `1cv8t\8.3.25.1374` (учебная), `1cv8\8.3.25.1374` без `comcntr.dll`, `1cv8\8.5.1.100` (не 8.3), `%LOCALAPPDATA%\Programs\1cv8\8.3.x` (для пользователя). Как в Части J — через `BILEM_SIMULATE` или подставной корень.
- Запись в [журнал агента](/stand/agent-app-v03-log).

## Чего не делать

- Не пытаться заставить работать учебную версию и не искать обходы её ограничений.
- Не ставить и не скачивать платформу 1С за пользователя.
- Не трогать чужие регистрации COM без явного «да» (правило `ComInUse` остаётся).
