**Дата:** 20.10.2026 · **Кто:** Слава (обсуждение с Cowork) · **Статус:** черновик плана, не в работе

Первым клиентом Bilem Cloud (WhatsApp, а не свой ИИ) будет Дарья — она дала добро подключить одну базу. Но она не горит: **сначала всё проходим сами** на тестовом клиенте. См. [Вход и аккаунты](/process/vhod-i-akkaunty), [решение 0005](/decisions/0005-put-k-kommercii), [решение 0011](/decisions/0011-csharp-net48). Макет агента: `minidesk/docs/mockups/bilem-agent-cloud-switch.html`.

## Шаги

| # | Шаг | Кто |
| --- | --- | --- |
| 1 | **Номер Zadarma**: купить один номер в пул (на месяц/год), завести на нём WhatsApp для Bilem, повесить нашего ИИ-агента. Сначала — демо/песочница на тестовой базе стенда | Слава (покупка), Воздух |
| 2 | **Тестовый клиент «Вова»** (бета-тестер СКП, свой телефон): регистрация на app.bilem.ai, организация, тариф, привязка агента, WhatsApp — весь путь клиента проходим сами | Слава + Cowork |
| 3 | **Тариф вручную** из bilem.dev → Клиенты: «Бета-тестер» — бесплатно, все функции, со сроком; в кабинете клиента видно, какой тариф | Воздух |
| 4 | **Привязка агента к кабинету кодом**: в кабинете «Подключить Bilem Agent» → длинный код на 10 минут (кабинет защищён входом) → агент вводит код и обменивает его на постоянный ключ компьютера → дальше канал без кода | Воздух (кабинет), Земля (агент) |
| 5 | **Облачный канал в службе агента**: кнопка «Подключить к Bilem Cloud» / «Отключить» — без переустановки (макет выше) | Земля |
| 6 | **Тарификация**: облако считает базы, отданные в канал («1 из 1»), и проверяет оплату; не оплачено — канал на паузе, локальный MCP работает | Воздух |
| 7 | **Дарья**: регистрация, тариф «Бета-тестер», установка агента вместе со Славой, номер WhatsApp из шага 1 переводим на неё (из песочницы в боевой) | Слава + Дарья |
| 8 | Потом: платный тариф, счёт на оплату из bilem.dev | Воздух |

Вход в кабинет (Google, Microsoft, Facebook, «email + код» через AWS SES) — само собой разумеется до всего этого, отдельным шагом не считаем.

## ChatGPT и другие ИИ-агенты (тариф с облачным MCP)

**Аутентификация**: OAuth через тот же вход, что в кабинете (Google, Microsoft…). **Авторизация**: есть ли у организации оплаченный тариф с этой функцией. Нет — отказ. Агенту на компьютере клиента OAuth не нужен: ему хватает кода привязки (шаг 4).

## Разделение работ

- **Земля — только «земное»:** всё, что стоит у клиента на Windows: Bilem Agent, служба, облачный канал, установщик.
- **Воздух — облако:** кабинет app.bilem.ai, тарифы, bilem.dev → Клиенты, приёмная сторона канала, WhatsApp.
- Стык — протокол канала агент↔облако и обмен кода привязки на ключ: описать одной страницей до начала работ.

## Служба

- Служба Windows **уже есть** (часть I, `Bilem.Agent.Service`, C# .NET 4.8, подписана). На Go не переходим — [решение 0011](/decisions/0011-csharp-net48) заменило Go из [0005](/decisions/0005-put-k-kommercii).
- Предложение Cowork: служба ставится **всем** (держит MCP после перезагрузки — то, на чём падал сервер Инны), а платная часть — только облачный канал внутри неё, включается кнопкой. Ждёт решения Славы.

## Убрали

- **Вход поддержки в кабинет клиента** (просмотр под пользователем) — **не делаем** (Слава, 20.10): непонятно, что там искать. Нужна информация — через тикет поддержки или по TeamViewer, когда клиент сам даёт доступ. Поддержка — платная, для Enterprise; бесплатные пользователи — в GitHub.

## Чего не делать

- Не делать оплату картой и автосписания до первого живого клиента — сначала вручную.
