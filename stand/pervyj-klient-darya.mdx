## Разделение работ

- **Земля — только «земное»:** всё, что стоит у клиента на Windows: Bilem Agent, служба, канал в облако, установщик.
- **Воздух — облако:** кабинет app.bilem.ai, тарифы, вход поддержки, bilem.dev → Клиенты, приёмная сторона облачного канала, WhatsApp.
- Стык Земли и Воздуха — протокол канала агент↔облако: описать одной страницей до начала работ.

## Служба и язык

- Служба Windows **уже есть** (часть I, `Bilem.Agent.Service`, C# .NET Framework 4.8, подпись кода есть): держит MCP после перезагрузки. Писать новую на Go не нужно — [решение 0011](/decisions/0011-csharp-net48) заменило Go из [0005](/decisions/0005-put-k-kommercii). Облачный канал — новый модуль внутри этой службы.
- Идея Славы: в дистрибутиве служба есть всегда, а платная часть включается кнопкой, без переустановки; обратно — тоже кнопкой. **Открытый вопрос:** ставить ли саму службу в бесплатном режиме (она же держит MCP после перезагрузки) и включать кнопкой только облачный канал — или ставить службу только при переходе на Cloud.

## Чего не делать

- Не входить в кабинет клиента без его включённого разрешения и не писать от его имени — только просмотр (политика конфиденциальности: «доступ команды — только для поддержки по обращению»).
- Не делать оплату картой и автосписания до первого живого клиента — сначала вручную.
