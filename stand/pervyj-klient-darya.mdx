**Дата:** 20.10.2026 · **Кто:** Слава (обсуждение с Cowork) · **Статус:** черновик плана, не в работе

Первым клиентом Bilem Cloud (WhatsApp, а не свой ИИ) будет Дарья — она дала добро подключить одну базу. Но она не горит: **сначала всё проходим сами** на тестовом клиенте. См. [Вход и аккаунты](/process/vhod-i-akkaunty), [решение 0005](/decisions/0005-put-k-kommercii), [решение 0011](/decisions/0011-csharp-net48). Макет агента: `minidesk/docs/mockups/bilem-agent-cloud-switch.html`.

## Как агент переключается (решено Славой 20.10, по макету)

- **Либо бесплатно, либо платно.** По умолчанию — бесплатный режим: локальный MCP `127.0.0.1` для своего ИИ. На вкладке **MCP** блок **«MCP в облаке — Bilem Cloud»** с галочкой «Включить» (как включение на вкладке SMTP). Включили — локальный MCP выключается и становится серым. Сняли — обратно бесплатно, без переустановки. Одновременно оба режима агент не держит: нужно и то и другое — второй сервер с Bilem.
- **Отдельной вкладки «Bilem Cloud» нет.**
- **Каждая база подключается к облаку отдельно** — на сервере может быть сотня баз, в облако идёт только нужная. В блоке: адрес облака `https://mcp.bilem.ai` (прописан), логин (e-mail кабинета), таблица баз этого компьютера с кнопкой «Подключить…» у каждой.
- **Подключение базы:** «Подключить…» → браузер, кабинет app.bilem.ai (вход через Google / Microsoft) → «Компьютер BUH-SERVER просит подключить базу … к вашей организации» → кабинет показывает код → код в агент → база в облаке. Код на 10 минут и один раз; дальше служба держит связь сама с ключом компьютера. Лимит баз считает кабинет.
- **Тарифа в агенте нет** — только в кабинете. В агенте статусы: «Работает», «На паузе — проверьте кабинет», «Нет связи с облаком», «Отключена в кабинете».
- После подключения в блоке — облачный адрес `https://mcp.bilem.ai/<организация>` для ChatGPT и claude.ai (без токена, вход через Google / Microsoft). WhatsApp и Telegram настраиваются в кабинете.

Вход в кабинет (Google, Microsoft, Facebook, «email + код» через AWS SES) — само собой разумеется до всего этого, отдельным шагом не считаем.

## ChatGPT и другие ИИ-агенты

**Аутентификация**: OAuth через тот же вход, что в кабинете (Google, Microsoft…). **Авторизация**: есть ли у организации оплаченный тариф с этой функцией. Нет — отказ. Это вход «кто спрашивает». Подключение базы кодом — другой вход: «на каком компьютере база» (служба без человека в Google не входит).

## Разделение работ

- **Земля — только «земное»:** всё, что стоит у клиента на Windows: Bilem Agent, служба, облачный канал, установщик.
- **Воздух — облако:** кабинет app.bilem.ai, тарифы, bilem.dev → Клиенты, приёмная сторона канала, WhatsApp.
- Стык — протокол канала агент↔облако и обмен кода на ключ: описать одной страницей до начала работ.

## Служба

Служба Windows **уже есть** (часть I, `Bilem.Agent.Service`, C# .NET 4.8, подписана) и ставится всем: в бесплатном режиме держит локальный MCP после перезагрузки, в Bilem Cloud — облачный канал. На Go не переходим — [решение 0011](/decisions/0011-csharp-net48) заменило Go из [0005](/decisions/0005-put-k-kommercii).

## Убрали

- **Вход поддержки в кабинет клиента** — не делаем (Слава, 20.10): нужна информация — через тикет или TeamViewer, когда клиент сам даёт доступ. Поддержка — платная, для Enterprise; бесплатные — в GitHub.
- **Вкладка «Bilem Cloud» и тариф в агенте** — не нужны (Слава, 20.10).

## Чего не делать

- Не делать оплату картой и автосписания до первого живого клиента — сначала вручную.
