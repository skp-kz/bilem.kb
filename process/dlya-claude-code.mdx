## Правила карточек — вся история в карточке

<Warning>
  С 21.10.2026 задачи живут на доске **bilem.dev** (MCP `bilem-dev`), не только в чате. Правила те же для всех агентов (Земля, Воздух, Кура, Арман, Buddy) и зашиты в `instructions` MCP-сервера.
</Warning>

Страница KB — **что сделать** (ТЗ). Карточка — **ход работы** (кто взял, что сделал, что не вышло, как проверить). Обычно Слава кидает в чат ссылку на страницу KB.

1. **Любая задача — в карточке.** Пришла ссылка на kb.bilem.ai или задача словами — найди карточку: `list_cards` с `q` = ссылка или ключевые слова (ищет по названию, тегам и описанию). Нет — создай на себя: доска `stand`, ссылка на страницу KB в описании. Номер назови Славе.
2. **Взял — отметь:** назначь себя, `progress`, комментарий «взял(а), план: …».
3. **Каждый итог — комментарием в карточку:** сделано / сделано частично / не сделано / ошибка. Ошибка и блокер — тоже: что случилось, что пробовал, что нужно от Славы. Ответ в чате дублирует карточку, но не заменяет.
4. **В комментарии:** что сделано; как проверить (версия, PR/коммит, адрес, команда); ссылка на KB, если работа по ней или ты её обновил; скриншоты для интерфейса.
5. **Вопрос Славе** — в карточку и в чат.
6. **Закрытие:** свою — сам (`done`), если приёмка не нужна; чужую не закрываешь — «готово, проверь», переносит автор.
7. **MCP недоступен** — скажи в чате «в карточку не записал(а): MCP недоступен» и запиши, когда доступ вернётся.

```text
Итог: сделано | сделано частично | не сделано | ошибка
Что: …
Как проверить: …
KB: https://kb.bilem.ai/…
Дальше / нужно от Славы: …
```

Тег в названии назначает исполнителя: `#земля`, `#воздух`, `#кура`, `#арман`, `#монтаж`. Пароли, токены, ключи и данные клиентов в карточки не пишем.

## Где что писать

| Что | Куда | Как |
|---|---|---|
| Задача, ход работы, итог, ошибка | карточка на bilem.dev (MCP `bilem-dev`) | `comment_card` — см. «Правила карточек» выше |
| Код по репо `bilem.cfe` | GitHub issue в `bilem.cfe` | `gh issue comment N --body "…"`; ссылку на issue/PR — в карточку |
| Код | ветка `cfe/N-…` → PR с `Closes #N` | см. [Цикл задачи](/process/workflow) |
| Знание, которое пригодится снова | эта база, раздел `onec/` или `decisions/` | admin MCP `mcp.mintlify.com` или git в `skp-kz/bilem.kb` |
| Итоги встречи | `meetings/ГГГГ-ММ-ДД.mdx` | обычно пишет Кура из tl;dv |
| Журнал сессии | `bilem.cfe/docs/journal.md` | новые сверху |

<Tip>
  Правило: если ты что-то выяснил про 1С и это заняло больше 10 минут — запиши в `onec/`. Следующий агент не будет искать заново.
</Tip>

## Подключения

```powershell
claude mcp add --transport http mintlify https://mcp.mintlify.com   # эта база: читать и писать
gh auth status                                                       # GitHub: issues, PR, доска
```

MCP самой cfe (`bilem`) — в `.mcp.json` репо `bilem.cfe`, заработает после публикации базы и токена.
