**Участники:** Слава, Инна (Protax) · **Формат:** созвон, ~20 минут

## Итоги

- **Инна согласна стать бета-тестером Bilem.**
- У Инны есть **OpenClaw**, агента зовут **Саги**. Он в одной сети Tailscale с её базами 1С. Доступ к нему у Славы был — найдёт.
- Начинаем **с копии одной её базы**, не с рабочей.
- **Главный запрос — акт сверки.** Его чаще всего просят клиенты, и больше всего он отвлекает бухгалтера.
- У OpenClaw Инны пока **нет WhatsApp**: Инна оформляет SIM-карту, чтобы отсканировать QR-код.
- **Режим пилота — Developer:** Bilem Agent рядом с базой + её OpenClaw (Саги) по MCP. Bilem Cloud не нужен.

## Второй пилот — Дарья

- Дарья (бухгалтер, согласилась 20.10, см. [Респонденты](/golos/respondenty)) — пилот **Bilem Cloud с WhatsApp**. Номер Zadarma покупает Слава позже.
- Для этого сейчас настраиваем вход в кабинет под своим именем (OAuth-приложения Bilem.ai в GitHub, Microsoft, Google, Facebook) и юридические страницы — см. [решение 0015](/decisions/0015-yuridicheskie-ssylki).

| Земля | задача [Пилот Инны — акт сверки на её базе](/stand/pilot-inna) |
| Слава | купить номер Zadarma для Дарьи — после готовности облака |
