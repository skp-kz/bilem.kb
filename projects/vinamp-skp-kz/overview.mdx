Этот раздел хранит исходные мысли о личном веб-плеере и общий контекст для дальнейшей совместной работы с AI. Название раздела: **проект VINAMP SKP KZ**. Адрес плеера: [**https://winamp.skp.kz**](https://winamp.skp.kz) (запасной — `vinamp.pages.dev`).

## Статус

**21.10.2026 — фронтенд работает** (проверено Славой): [https://winamp.skp.kz](https://winamp.skp.kz)

- Код: репозиторий `minidesk`, папка `vinamp/` (`site/index.html`, `build.mjs`, `music/`), деплой — `cd ~/Documents/GitHub/minidesk && ./deploy-vinamp.sh` (Cloudflare Pages, проект `vinamp`, свой домен `winamp.skp.kz`).
- Фон — юрта, три сцены из Higgsfield (степь на закате, ночь, вид изнутри), переключаются миниатюрами справа внизу. Пока по прямой ссылке Higgsfield — выбранный фон сохранить в репозиторий.
- Плеер — Webamp 2 (`captbaritone/webamp`): справа, плейлист под ним на всю высоту, эквалайзер по кнопке EQ. Подпись «Winamp · юрта».
- Плейлист — из папки `vinamp/music/` (сейчас две демо-песни, сгенерированы, без лицензий) + первым «DJ Mike Llama — Llama Whippin' Intro» (с jsDelivr, как в примере Webamp).
- Выключено: Add / Rem / List / Eject, перетаскивание файлов, меню «Play file». Подписи ADD/REM на плейлисте остаются — это картинка скина; уберём своим скином.
- `wa.skp.kz` не взяли — там CNAME на Cloudflare Tunnel (похоже на relay WhatsApp), не трогать.
- **Сайт пока открыт всем** — личную музыку не класть до PIN-кода.

## Следующий шаг (не сейчас, напоминание)

1. **PIN-код на вход** — один простой числовой, без логинов. Проверка на сервере (Pages Function / middleware), cookie на N дней; закрыты и страница, и сами аудиофайлы (не только интерфейс).
2. **Песни из расшаренной папки** — плейлист собирается из папки на диске SKP (ownCloud, `disk.skp.kz`): положил файл — появился в плеере. Файлы отдаются только после PIN.

## Пометки Славы 21.10 (утро, по дороге на работу)

- **Сначала фронтенд**, без закрытия и без красивого домена: посмотреть, как выглядит и играет.
- **Фон — юрта** («скучаю»): красивый фон из Higgsfield, поверх — Webamp.
- **Папка с музыкой захардкожена.** Никакого выбора папки и добавления файлов в плеере. Слава сам кладёт песни в одну папку — они сами появляются в плейлисте.
- **Что работает в плеере:** play, stop, пауза, выбор песни в плейлисте, эквалайзер, громкость. **Что выключено:** «Добавить файл / папку / URL», Eject, перетаскивание файлов, загрузка плейлистов.
- **Источник:** сейчас демо-MP3 рядом с плеером на Cloudflare; потом — папка на диске SKP.
- Зачем: слушать на работе свою музыку и песни дочери — личные подписки на рабочем компьютере закрыты.

## Цели

Сделать личный «Winamp for Web», чтобы слушать свою музыку на работе прямо в браузере, без рекламы YouTube. Источник музыки: выбранные файлы на Synology / диске SKP, включая собственные записи, записи дочери и редкий личный архив. Публичный музыкальный сервис не планируется.

## Идеи владельца

- Сохранить ощущение классического Winamp: привычные окна плеера, плейлист, эквалайзер и скины.
- Визуальные ориентиры: запомнившийся скин Metallica; своё оформление с казахской юртой (выбрано первым).

## Безопасность (при закрытии)

- Закрыть и интерфейс, и выдачу аудиофайлов: закрытая страница сама по себе не должна оставлять музыку доступной по публичным MP3-ссылкам.
- Плееру — только чтение выбранной музыкальной папки. Не открывать в интернет DSM и не давать доступ к другим папкам.
